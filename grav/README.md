# Grav-Plugin agff-drywatch

Baustein `[drywatch]` für Seiten: Rechner für die Heubelüftung (Wasserentzug, Trocknungsphase, Empfehlung) mit
Hintergrundwissen, manuelle Eingabe ohne Sensoren. Gebaut aus dem Repo
[agff-drywatch-hacs](https://github.com/AGFF-ADCF-APF/agff-drywatch-hacs) (gleicher Kern wie die Home-Assistant-Card).

```
[drywatch]
[drywatch hoehe=800 flaeche=120 luftmenge=13 wissen=nein]
```
